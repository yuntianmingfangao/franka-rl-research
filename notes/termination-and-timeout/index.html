terminated、truncated、done：三个词，不是一种结局

timeout 不等于成功；一个 done 字段也不能自动决定所有算法的 bootstrap mask。

2026-10-141 分钟阅读公开摘要 · 非实时状态
数据契约奖励终止语义

termination 表示任务定义的终止，truncation 表示时间等外部边界造成的截断。具体实现的 done 与 not_done 必须沿原源码解释，不能只看名字。

同一条历史轨迹的例子

已核的 313 步轨迹最后一条 truncation 和源 done 为 true，但 termination 始终 false。原 HIL 取 termination 作为 done，于是 mask 仍为 1。公开展示会同时保留这几个事实，不把 timeout 重标成成功。

  • 成功标签需要独立任务来源，不能从文件结束或 stopped 推断。
  • 人工中止与 unknown 不补写成 success。
  • 不同算法的两种 mask 语义需要单列，不能为统一格式随手合并。
  • 来源联接必须按实际身份和时间，不靠数组位置猜 next。
