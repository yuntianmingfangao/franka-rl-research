HIL-SERL：权重走向 actor，历史反馈回到 learner

独立原 actor 接收完整策略参数；313 条历史转移进入原 replay，64 条原 learner 取样核验通过。

2026-10-142 分钟阅读公开摘要 · 非实时状态
HIL-SERL权重同步数据回传

此前固定历史池已完成 1000 次原生 HIL 更新与完整训练状态恢复。这次补齐两个分开的工程环节：训练参数发布到独立 actor，以及已有记录经原数据通道回到 learner 的 replay。

从训练存档到独立 actor

原 Agentlace 发布和回调实际发生在不同 OS 进程。独立 actor 起始参数与训练参数不同，收到参数后逐项一致。六个相关历史观测的原 sample / mode 输出在两侧逐值相等，采样前后完整状态未变。参数同步不意味着 actor 的优化器、target 或计数也同步。

从历史转移到原 replay

完整历史转移313
原取样核验64
本轮新增训练0

313 条转移分两批进入原 ReplayBufferDataStore。全字段值、dtype 与相邻观测链接经过核验；正常确认后重复 update 没有新增插入。原 learner iterator 实际抽取两批共 64 条，每条都对应收到的历史源成员。

终止语义不能省略

这条历史轨迹的奖励全为 0，最后一步是截断。原 HIL done 使用 termination，不能把 timeout 改成成功，也不能因为传输完成就称任务回合成功。

仍缺少什么

这是历史记录运输与原生消费，不是新采集、非空干预池回传或断线 exactly-once 保证。持续现场反馈、人类接管、安全复位和统一自主评估仍需分别验收。
